# Sidebar Prototype

Интерактивный прототип бокового меню (MWS Product Ordering), сверстанный из макета Figma.

## Что внутри
- `index.html` — разметка
- `styles.css` — стили и дизайн-токены (светлая/тёмная темы)
- `script.js` — логика (активный пункт, сворачивание L/M/S, меню профиля, темы)
- `icons/` — иконки и ассеты

## Возможности
- Три состояния сайдбара: Полное (220px) / Компактное (80px) / Только иконки (68px)
- Меню профиля с подменю «Меню» и «Тема»
- Светлая и тёмная темы
- Тултипы в свёрнутом состоянии

## Запуск
Открыть `index.html` в браузере — это статический сайт, сборка не требуется.

> Примечание: фирменные шрифты MTS Compact / MTS Wide подключены через `local()` и берутся из системы. На машинах без этих шрифтов будет системный запасной.
